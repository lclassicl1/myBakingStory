# 메인화면 초기 요구사항

작성일: 2026-05-23

## 목표

베이킹 커뮤니티의 첫 화면은 로그인 여부와 관계없이 접근 가능해야 한다. 사용자는 메인화면에서 각 게시판의 최신 글을 빠르게 훑어보고, 필요한 게시판으로 이동할 수 있어야 한다.

## 접근 정책

- 메인화면은 로그인/비로그인 사용자 모두에게 공개한다.
- 게시판 목록과 최신 글 영역은 로그인 여부와 관계없이 동일한 UI 구조로 보여준다.
- 단, 비공개 성격의 게시판은 사용자의 인증 상태에 따라 노출 문구와 데이터가 달라질 수 있다.

## 초기 게시판

초기 메인화면에 노출할 게시판은 다음과 같다.

| 게시판 | 설명 | 공개 범위 |
| --- | --- | --- |
| 공지사항 | 서비스 운영 공지, 업데이트 안내 | 전체 공개 |
| 모두의 레시피 | 모든 사용자가 공유하는 공개 레시피 | 전체 공개 |
| 나만의 레시피 | 로그인한 사용자가 작성한 개인 레시피 | 본인만 공개 |
| 자유게시판 | 베이킹 관련 자유 대화 | 전체 공개 |
| 이벤트 게시판 | 진행 중인 이벤트와 당첨 안내 | 전체 공개 |
| 건의 게시판 | 서비스 개선 의견과 제안 | 전체 공개 |

## 메인화면 게시글 노출 규칙

- 각 게시판별 최신 글을 리스트 형태로 보여준다.
- 각 게시판의 전체 글을 모두 보여주지 않는다.
- 게시판별 노출 개수는 최신순 3~5개 정도로 제한한다.
- 기본 노출 개수는 코드에서 쉽게 조정할 수 있어야 한다.
- 게시판 종류와 개수는 이후 늘어날 수 있으므로, 메인화면은 게시판 설정 배열을 기반으로 렌더링한다.
- 메인화면 자체는 로그인 여부와 관계없이 열람 가능하지만, 게시판으로 이동할 때는 로그인 여부를 검증한다.
- 로그인하지 않은 사용자가 게시판으로 이동하면 실제 게시글 목록 대신 로그인이 필요하다는 메시지를 보여준다.
- 메인화면에서 게시판 이동 버튼, 게시글 목록, 글쓰기 버튼을 클릭할 때 로그인하지 않은 상태라면 별도 페이지로 이동하지 않고 로그인 필요 모달을 보여준다.

## 글쓰기 진입 규칙

메인화면의 일부 게시판에는 게시판 이동 버튼 옆에 글쓰기 `+` 버튼을 제공한다.

| 게시판 | 글쓰기 버튼 | 작성 권한 |
| --- | --- | --- |
| 공지사항 | 표시 | 사이트 운영자 |
| 모두의 레시피 | 미표시 | 추후 정책 결정 |
| 나만의 레시피 | 표시 | 로그인한 본인 |
| 자유게시판 | 표시 | 로그인한 사용자 |
| 이벤트 게시판 | 미표시 | 추후 정책 결정 |
| 건의 게시판 | 표시 | 로그인한 사용자 |

권한이 없는 사용자가 글쓰기 화면에 접근하면 권한 안내 메시지를 보여준다.

메인화면의 글쓰기 `+` 버튼을 클릭했을 때 로그인하지 않은 상태라면 별도 페이지로 이동하지 않고, 현재 화면 위에 팝업 형태로 다음 안내를 보여준다.

```text
로그인을 하지 않으면 글을 작성할 수 없습니다
```

메인화면의 게시판 이동 버튼과 게시글 목록을 클릭했을 때 로그인하지 않은 상태라면 다음 안내를 모달로 보여준다.

```text
로그인을 하지 않으면 볼 수 없습니다
```

직접 URL로 글쓰기 화면에 접근하는 경우에는 보호 페이지에서 동일한 권한 안내를 보여준다.

인증 상태는 Supabase session과 `public.profiles`의 role 값을 기준으로 판단한다.

## 나만의 레시피 처리 규칙

`나만의 레시피`는 로그인한 사용자가 작성한 본인 글만 볼 수 있는 게시판이다.

비로그인 상태:

- 실제 개인 레시피 목록을 보여주지 않는다.
- 메인화면의 동일한 목록 영역에 다음 문구를 표시한다.

```text
이 레시피는 공개되지 않았습니다
```

로그인 상태:

- 로그인한 사용자가 작성한 개인 레시피를 최신순으로 보여준다.
- 다른 사용자의 개인 레시피는 보여주지 않는다.

## UI/CSS 원칙

- 메인화면과 모든 게시판 화면은 일관된 UI를 사용한다.
- 게시판 섹션, 게시글 목록, 게시글 항목, 빈 상태, 잠금 상태 등은 공통 컴포넌트로 관리한다.
- CSS는 각 페이지에 흩어두지 않고 공통 스타일에서 관리한다.
- 게시판이 추가되어도 같은 컴포넌트와 스타일 규칙을 재사용한다.
- 모바일 웹뷰와 데스크톱 웹에서 같은 정보 구조를 유지하되, 화면 크기에 따라 반응형으로 배치한다.

## 초기 구현 범위

이번 단계에서 구현할 범위는 다음과 같다.

- Next.js 기반 웹 앱 생성
- 메인화면 구현
- 초기 게시판 설정 데이터 구성
- 게시판별 최신 글 미리보기 UI 구현
- `나만의 레시피` 비로그인 잠금 문구 구현
- 공통 게시판 UI 컴포넌트 구성
- 공통 CSS 기반 스타일 구성
- 로컬 개발 서버에서 확인 가능하도록 구성

## 향후 확장 고려사항

- 새 기능은 [DB 연동 개발 가이드](./DB_INTEGRATION_GUIDE.md)를 기준으로 DB 테이블, RLS 정책, migration SQL, server action/API, UI 연결을 함께 설계한다.
- Supabase 인증 연동
- 게시판별 실제 DB 데이터 연동
- 로그인 사용자별 `나만의 레시피` 필터링
- 게시판 상세 화면
- 게시글 작성/수정/삭제
- 검색, 태그, 이미지 업로드
- Capacitor 기반 모바일 웹뷰 앱 전환
